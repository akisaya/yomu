# 编辑与设计取舍记录

这一页的目标读者是中文母语的日语学习者（N3 上下）。所有规则都来自实际返工，照做可以少改三轮。

## 一、首屏文案

### 可复用公式

**处境 → 手法 → 三个具体物 → 落点（原句）**

四句之内说完。不要形容词，不要评价，不要替读者下结论。

定稿示例：

> 离了婚的男人，写给前妻的信。通篇没有一句“我爱你”——他写猫，写樱花，写烤红薯，把婚姻拆成一张清单：洗手台上并排的牙刷，被窝里碰到的脚，冰箱里不知何时消失的布丁。写完这些，他才问：要不要一起变老。

### 被否的版本与原因

| 版本 | 用户反馈 | 问题 |
|---|---|---|
| 「离婚届已经递出去了。在等着春天的那间旧公寓里……」 | 「这句话很怪，离婚信吗」 | 直译 `離婚届を出す`；中文不这么说，还让人误以为这是封离婚通知 |
| 「两个人已经离了婚。在目黑川边那间等着春天的旧公寓里，滨崎光生坐下来……」 | 「写得非常不好」 | 先交代时间地点，镜头对准布景；「通篇都是……只有……」是并列凑句，没有实物 |
| 「把一句台词，当一篇文章来读。」 | 语气太文、太像口号 | 立论可以，但和「反复品味」的个人口径不一致 |
| 「喜欢的台词，反复品味。」 | 太短，缺主语 | 收敛过度 |
| **「阅读是一种感觉，喜欢的台词值得反复品味。」** | 通过 | 有主语、有判断、有节制 |

### 语体

- 用书面语。删掉「你」「点进去」「看看」「拆到能看见骨头」这类口语或比喻。
- 不混搭比喻与实物：一个句子里只允许一种修辞。
- 不写「一句话：X 只是 Y」这种讨论腔，也不写「不得不说」「真的很」这类口头强调。

## 二、页面结构

固定五节，顺序不要变：

1. 首屏（竖排标题 + 朱印 + 引文）
2. 手纸（原文 + 译文）
3. 精読（五层折叠卡）
4. 単語帳（搜索 + 筛选）
5. 文法メモ（句型 + 原文例句）

**不设测验。** 曾做过 7 题即时判分的选择题，被要求整块删除（连同 CSS/JS/页脚入口）。这是读物，不是练习册。

## 三、版式

### 一条左对齐线

小节标题、作品行、四栏说明，全部落在同一个 `wrap` 左边距上。不要为了放序号而给某一级单独缩进。

### 编号只允许一层

曾经同时存在三级等宽小字编号：

```
01  収録            ← 小节
01  ドラマ……        ← 作品行
01  骨格            ← 四栏
```

用户的评价是「看起来有点重复」。最终方案：

- 只保留小节号，并且**与标题同行**：`01 収録`（flex + `align-items:baseline`）
- 删除作品行、四栏的序号与对应样式
- 删除为序号预留的 56px 悬挂栏位——只有一级编号时，那会变成空洞

### 其他

- 按钮只写文字。箭头（↓ ↘ ↗）和时间码都不要；时间码留在页脚出处。
- 小节标题下不加副句。两句解释会让标题失去重量。
- 首屏不放「这封信讲了什么」的二手解说；要么给原文引句，要么留白。

## 四、中译的常见错误（校对清单）

1. **顺序**：抽象句是否被挪到段末？原文的具体—抽象—具体结构是论证，不是修辞。
2. **惯用句**：`悲鳴を上げる`（尖叫）、`目を通す`（过目）、`手を貸す`（帮忙）——不要按字面译。
3. **加词**：译文里是否出现原文没有的「回忆」「其实」「终于」？
4. **抹平矛盾**：`一人ずつ二人で` 这种刻意的矛盾要保留，不要意译成通顺但失义的句子。
5. **人称**：日语常省略主语，中文补主语时要确认补的是谁。
